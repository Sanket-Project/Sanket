## Execution discipline

Follow AGENTS.md manually: brainstorming/design approval, writing-plans, strict RED → GREEN → REFACTOR, sequential executing-plans, review, verification. Superpowers is not an available Codex skill in this session; do not claim invocation.

Each task below targets one 2–5 minute behavior. If a task exceeds that size, split it before coding and retain the same acceptance criteria. Each production change starts with the named failing test, an observed failure for the intended reason, the minimum implementation, and the same test green. Collection errors prove a missing module only for the initial scaffold; subsequent RED observations must exercise the behavior. Refactor only while green. Full verification jobs may take longer.

Named new files and tests are proposed targets, not existing capabilities. Prefer extending an existing equivalent file when inspection shows that it owns the behavior. Keep a RED/GREEN log per phase under `docs/audit/2026-10-27-ai-phase-N/`, with command, expected failure, actual failure, final result, and source revision. Never include raw workbook rows, prompts, credentials, or connection strings in logs.
