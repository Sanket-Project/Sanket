# Redesign workflow assets

This folder stores the project-specific outputs and rules produced with the installed design skills. It intentionally does not duplicate the installed skill packages, so their guidance can continue to update independently without leaving stale copies in the repository.

- Product Design: audit, visual ideation, selected-image implementation, and design QA.
- UI/UX Pro Max: product pattern, chart, accessibility, navigation, and React guidance.
- ImageGen: dashboard directions and fashion catalogue imagery.
- Composition Director: grid, focal hierarchy, grouping, and density checks.
- Typography Director: type hierarchy, measure, and contrast rules.
- Brand Intelligence: Sanket identity locks and sourced connector-brand asset policy.
- Visual QA: generated-asset and implementation release gates.
